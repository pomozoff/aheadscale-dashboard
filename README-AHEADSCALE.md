# Aheadscale dashboard

Public downstream of NetBird dashboard v2.94.0, source dab8fcc88ddbd738e03a87fda0fa89d50f3b3180.
User-facing name, marks and primary blue palette follow Aheadscale. Existing OIDC client IDs, storage keys, API fields and licenses remain compatible.
The upstream AGPL license and attribution remain in LICENSE/AUTHORS. Source: https://github.com/pomozoff/aheadscale-dashboard.
Build with pinned Node 24.19.0, npm ci, npm run build; Docker serves the static export with the existing runtime config mechanism.
