# Веб-панель Aheadscale

Панель управления частной сетью [Aheadscale](https://aheadscale.ru): устройства, пользователи, доступы и настройки сети. Интерфейс использует собственные название, логотип, страницы входа и ссылки помощи Aheadscale.

Пользователь устанавливает клиент, входит или создаёт аккаунт в браузере и подключает устройства к своей сети. На этапе прототипа бесплатный аккаунт ограничен пятью устройствами.

- [Помощь пользователю](https://github.com/pomozoff/aheadscale-client/blob/aheadscale/docs/aheadscale/user-guide.md).
- [Исходный код клиента и сервера](https://github.com/pomozoff/aheadscale-client).

## Разработка и сборка

Используйте Node.js 24.19.0 и зафиксированный `package-lock.json`.

```sh
npm ci
npm run build
```

Результат статической сборки находится в `out/`. Файл `docker/Dockerfile.aheadscale` упаковывает его в образ панели; адреса сервера и авторизации задаются при запуске контейнера.

Обычные команды разработки:

```sh
npm run dev
npm run test:unit
```

Для работы панели нужна настроенная серверная часть Aheadscale. Приватные параметры подключения и секреты не входят в этот репозиторий.

## Лицензии и происхождение

Панель основана на открытом проекте NetBird Dashboard. Исходная лицензия, уведомления об авторах и технические идентификаторы совместимости сохранены. Оригинальная инструкция базового проекта находится в [docs/upstream/README.md](docs/upstream/README.md); она описывает исходный проект, а не размещённый сервис Aheadscale.
